# 换图专属音效 —— 实现说明

> 需求：TF 相册每切换一张图（每张怪物图 / 地图图），播放一段只属于这张图的音效。
> 本文记录改了哪三处、音高怎么排、怎么自己改，以及怎么验证。

---

## 一、为什么这么加

播放器的换图链路由 `media_ctrl → sd_img → media_framebuffer` 完成，最终"当前显示第几张"
落在 `media_cdc` 的 `p_shown`（顶层叫 `m_shown`，6bit）。**它和音源模块 `sound` 同在
`clk_pix` 域**，所以不需要任何跨时钟处理，检测它的变化就能卡住"这一张已经上屏"的时刻。

音效侧有两个现成通道，各有问题：

| 方案 | 问题 |
|---|---|
| 复用 `sound` 的 `sfx_id`（4bit，1~15）| 只有 15 个编号，25 张图不够分；而且换图音会顶掉受击 / 击杀音 |
| 新开一路 chime 声部（**采用**）| 独立相位累加器，可与游戏音效、BGM 同时发声 |

顺带说明：`mus_on` 只是停止 BGM 换音，三路振荡器要等包络衰减（约 0.5s）才真正静音，
所以仿真里**不能**用 `mus_on=0` 当"静音"来做测频，必须直接测 chime 振荡器（见第五节）。

## 二、改了哪三处

### 1. `rtl/common/key_debounce.v` → `sound` 模块

新增三个端口：

```verilog
input  wire [23:0] chime_step,   // 相位步进, 0 = 不发声
input  wire [15:0] chime_len,    // 时长(32kHz 采样数)
input  wire       chime_trig,    // 单拍触发
```

新增第 4 路声部（与 sfx 的 `erun/eph/eleft` 结构完全一致，便于照抄维护）：

```verilog
reg [23:0] cstep; reg [15:0] cleft; reg [23:0] cph; reg crun;
always @(posedge clk or negedge rst_n) begin
    if (!rst_n) begin cstep<=0; cleft<=0; cph<=0; crun<=1'b0; end
    else if (chime_trig && chime_step != 24'd0) begin
        cstep <= chime_step;
        cleft <= (chime_len==16'd0) ? 16'd1 : chime_len;
        cph   <= 24'd0;
        crun  <= 1'b1;
    end else if (crun && stk) begin
        cph <= cph + cstep;
        if (cleft <= 16'd1) begin crun<=1'b0; cleft<=16'd0; end
        else                cleft <= cleft - 16'd1;
    end
end

wire signed [7:0] chime_wave = cph[23] ? -8'sd44 : 8'sd44;
wire signed [7:0] s4 = (crun && (cleft > 16'd96)) ? chime_wave :
                       ((crun && cleft[6]) ? (chime_wave >>> 1) : 8'sd0);
```

混音里加一项：

```verilog
wire signed [9:0] mix = ... + {{2{s3[7]}}, s3} + {{2{s4[7]}}, s4};
```

> 采样节拍 `stk` 是 32kHz（`SAMPLE_HZ`），相位步进按
> `step = 频率 × 2^24 / 32000 = 频率 × 524.288` 算——**按采样率算，不是按主频**，
> 这是本工程踩过的坑（按主频算会把音高压低 1250 倍）。

### 2. `rtl/common/key_debounce.v` → 新增 `img_chime` 模块

放在 `key_debounce.v` 文件末尾，**不要新建 .v 文件**：TD 会把手工加入工程的新文件
自动标成 `AutoExcluded`（不参与综合，变 black box），这是本项目已知的坑。

行为：

```
图号变化 → 连续稳定 8ms 才认账（换图过程中 shown_index 会跳若干中间值）
        → 第 1 音：基音，55ms
        → 第 2 音：上五度（step × 1.5），90ms
        → 回空闲
```

- 8ms 稳定判定：避免一次换图响好几声
- 两音动机听起来像"叮—咚"，比单音更容易分辨
- 图号相同不重复触发（只在 `index != idx_d` 时响）

### 3. `rtl/rpg_top.v`

```verilog
wire        img_chime_trig;
wire [23:0] img_chime_step;
wire [15:0] img_chime_len;

img_chime #(.CLK_HZ(PIXEL_HZ)) u_chime (
    .clk(clk_pix), .rst_n(rst_n),
    .index(m_shown), .count(m_count), .ready(m_cat_ready),
    .trig(img_chime_trig), .step(img_chime_step), .len(img_chime_len)
);
```

并把三根线接到 `u_snd`：

```verilog
.chime_step(img_chime_step),
.chime_len (img_chime_len),
.chime_trig(img_chime_trig),
```

## 三、音高表（25 张图怎么分）

表在 `img_chime.note_step()`，25 个值的半音偏移是**打散**的 0~24（每个半音用一次，
顺序乱），所以连续翻页不会听成爬音阶，但相邻两张的音程又是随机的。

| 图号 | 示例怪物 | 基音 | 上五度 |
|---|---|---|---|
| 0 | 史莱姆 | 261.6 Hz | 392.4 |
| 1 | 野兔 | 392.0 | 588 |
| 2 | 田鼠 | 311.1 | 466.7 |
| 3 | 蜂群 | 523.3 | 785 |
| … | … | … | … |
| 24 | 深渊领主 | 987.8 | 1481.7 |

改音高只需改 `case` 里的 24 位数：`step = round(频率 × 524.288)`。

常见改法：

- **只想每张图一个单音，不要上五度**：把 `C_N1` 分支里 `step <= step1 + (step1 >> 1)`
  改成 `step <= step1`，或把 `HOLD2` 调小。
- **按 5 个区域分组（同区同音）**：把 `note_step` 改成
  `note_step = TABLE[n/5]`，同区域的 5 张图共用一个音，区域之间换调。
- **换成一段固定旋律**：把 `img_chime` 的两音状态机扩成 N 音表（多几个 HOLD/TICK 常
  量即可），或干脆用 `tools/make_audio.py` 生成一小段 hex 当"曲目"来播。

## 四、上板步骤

1. TD 打开工程（`D:/jingsai/EG4_FastHigh/EG4_FastHigh.al`），确认 `key_debounce.v`
   仍在工程里且**没有被标 AutoExcluded**（本次改动都在这个已存在的文件内）。
2. 重新综合 / 布局布线 / 生成码流。
3. 下载 SRAM（或固化 Flash）。
4. 插卡上电，按键翻页，每换一张图应听到一个"叮—咚"，且每张图的音高不同。

如果翻页没声音、但游戏音效正常，优先查：

- `m_cat_ready` 是否拉高（目录没就绪前 `img_chime` 不出声，这是故意的）
- 卡上图片数量 `m_count` 是否为 0（0 张时不出声）
- 是否用的旧码流（改动要重新生成 bit）

## 五、验证

仿真测试台：`sim/iverilog/tb_img_chime.v`（空壳 `sim/iverilog/sdram_stub.v` 只为让
iverilog 能展开 `key_debounce.v` 里的 SDRAM 原语，不参与综合）。

```bash
cd D:/EG4S20_RPG_Game-main
tools/iverilog/bin/iverilog.exe -g2012 -o sim/iverilog/out/chime.vvp \
    sim/iverilog/tb_img_chime.v sim/iverilog/sdram_stub.v rtl/common/key_debounce.v
tools/iverilog/bin/vvp.exe sim/iverilog/out/chime.vvp
```

实测（25MHz 像素时钟）：

```
== 换到 index=2 (期望基音 311.1Hz) ==
  [trig 1] t=13.06ms  step=163120  len=1760
  基音  :   311.8 Hz   (step->311.1 Hz)
  [trig 2] t=68.44ms  step=244680  len=2880
  上五度:   467.7 Hz   (step->466.7 Hz)
== 换到 index=24 (期望基音 987.8Hz) ==
  [trig 3] t=175.98ms step=517874  len=1760
  基音  :   994.0 Hz   (step->987.8 Hz)
  [trig 4] t=231.36ms step=776811  len=2880
  上五度:  1445.8 Hz   (step->1481.6 Hz)
== 重复写同一图号, 累计触发 4 次 (期望 4: 两张图 x 2 音) ==
```

结论：每次换图恰好触发一次、基音与上五度都对，重复写同一图号不再触发。
测频与 `step` 换算值的偏差在 0.5%~2.5%，来源是仿真里按 25MHz（实际 25.175MHz）
估时 + 只取两个上升沿，不是 RTL 的问题。

要点：测频必须看 `u_snd.cph[23]`（chime 振荡器最高位），不能看 `dac`，否则测到的是
BGM 三路声部的音高。

## 六、代价

| 项 | 量 |
|---|---|
| 新增触发器 | 约 80 个（相位累加器 24 + 计数器 24 + 状态机若干）|
| 新增组合逻辑 | 一个 25 路 `case`（分布式 LUT，约 60 LUT）|
| 存储 | 0（音高表是常量，不占 BRAM）|
| 音频 | 混音幅度上限仍 ±120，chime 占 ±44，实测不会削顶 |

对 EG4S20 的 19600 LUT4 来说可以忽略。

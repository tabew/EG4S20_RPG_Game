# 消息功能合并与上板说明

## 合并范围

用户指定的两份 `.gitattributes`、`.gitignore`、`LICENSE`、`README.md`、`td_20261030_204358.log` 逐字节相同，因此没有用副本覆盖原文件。它们是配置、许可证、说明和历史日志，本身不是 FPGA 功能代码。

另对两份工程的有效 RTL、约束、文档、测试及主要生成脚本进行了比较。副本中实际新增的是 RPG 上下文提示与消息优先级仲裁，包括低血量／区域提示、强敌提示、商店提示排队，以及匹配的字体、字符串、指令 ROM 和资源生成器。本机原工程已合入这些变化。

新生成的 ROM 包装文件中的路径原本指向另一台电脑；合并后使用本机工程路径。字库、指令、字符串和地址表在隔离目录用本机生成器重新生成，结果与副本一致。生成器新增容量检查，避免容量超限后先写出不完整 ROM。

审查时修正了两项显示问题：回血脱离危险后清除旧的低血量警告；界面切换与自动重绘相遇时保留待处理的重绘请求。游戏数值和已有按键分工没有有意改动。

## 保留原功能

原 HDMI 音乐与音效、TF 图片播放器、手动／自动切图、四帧缓存、1×／2×／4×缩放、怪物旋转／镜像、彩虹频谱外框及板卡引脚／时钟约束保持。对应音视频、SDRAM 和怪物显示相关源码与合并前备份逐字节一致；综合结果还需实板验收。

- 普通短 K3：暂停／恢复自动图片；设置页短 K3：缩放。
- 长 K3：声音开关。
- RPG 战斗时长 K1／K2：怪物旋转／镜像；短按仍是战斗操作。
- RPG 战斗外框随实际音乐／音效变化。

## 验证与边界

新增消息的测试覆盖区域提示、优先级仲裁、商店提示、回血恢复、界面切换重绘及相关消息显示。部分边界测试使用仅存在于仿真的合成游戏状态，再通过真实按键与公开的字符写入接口检查；不是板上测试。

ROM 容量为字库 8192 行／指令 418 条／字符串 994 项，均未超过现有硬件容量。原 GUI 工程从 `syn_1` 重新综合、HIGH 布线并生成码流；37 项设计输入与冻结快照一致。3 个内部逻辑时钟与 5 组数据跨域约束检查无 setup／hold 违例。SDRAM 外部器件 IO 不是独立外部 IO 延迟 STA 证明，仍需实板检查。

## 上板检查

先选择 `build/merged_20261102/EG4_Merged.bit` 下载 SRAM。原 GUI 工程的正常输出 `D:/jingsai/EG4_Runs/phy_1/EG4.bit` 与该文件相同。建议依次检查：

1. 上电显示、游戏标题、职业选择、地图与商店的新增提示；低血量恢复后警告消失。
2. 攻击、技能、药水、逃跑与商店购买的原有操作。
3. 战斗时怪物旋转／镜像、彩虹外框、音乐与长 K3 静音。

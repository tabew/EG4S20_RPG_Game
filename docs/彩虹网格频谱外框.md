# 彩虹渐变网格频谱外框

本版按用户参考图，把原先零散的小频谱柱改成连续填充的彩虹渐变色块：细亮网格、暗色外沿和暖粉色内沿。不是复制参考图中的草莓或文字，修改对象仍是RPG战斗最外侧边框。

## 外观与音乐响应

- 顶部／底部每32逻辑像素分一格，格子为32×16；左右为16×32。
- 对角连续色相渐变，色块之间只有1逻辑像素分隔线，没有黑色柱间空隙。
- 每组真实FFT值控制色块亮度和内侧0～3像素的柔光带；较强频带更亮。
- 静音后光带消退，色块回到低亮状态，仍保留完整的彩框、网格和细描边。
- 颜色位置不按定时器随机跳变；音乐相关动态来自原有真实PCM／FFT，非假动画。

对比先前版本：框体轮廓固定整齐，主要用亮度和内沿光带表达能量，不再让柱高形成参差断边。

## 不改变的内容

范围仍为原外侧16逻辑像素，800×600兼容模式为约20物理像素；不会加宽覆盖姓名、生命条或按钮。内部怪物、血条、文字、地图及篝火保持原样。只有战斗外框启用，图片播放器不套此框。

长K1怪物旋转、长K2怪物镜像、长K3音乐／音效开关、短战斗键，以及图片1×/2×/4×缩放、缓存和自动播放都不改。

## 预览

build/neon/frame_preview.png来自实际Verilog渲染器的公开RGB输出，使用原始野兔ROM和代表性HP／MP测试画面。Pillow只转换文件格式并加标签，不伪造内部游戏图层；该图是软件RTL预览，不是板上实拍。build/neon_style中的样式图由实际抽取的RTL颜色函数计算，中心留空。

预览中的八组输入强度刻意不同，因此有的区段更暗。实际曲目变化时，各组亮度随频谱更新；持续单音可保持稳定，静音不等于彩框完全消失。

## 实现

仅修改rpg_video.v的频谱外框绘制块。原FFT、采样、音乐、怪物层、游戏核心、SDRAM、时钟与约束保持。启用和频带依旧在帧边界快照，坐标与RGB五拍流水线不变。

颜色采用六段色轮，hue=((x>>1)+(y>>1)) mod256，静态对角渐变；增益min(63,16+(min(level,120)>>1))。内侧柔光宽度为min(level,120)>>5，网格与内描边保留稳定亮度。RGB565输出，内容区RGB888链路不重新量化。

## 测试与构建

实际RTL样式测试：静音色块非黑、0～255各档亮度不减、120与255夹紧一致，均通过。640×480完整渲染器8组回归已完成：2,457,600有效像素，2,179,072个内容区像素与基准逐位一致，278,528个外框像素覆盖、1,584个完整色块探针；固定网格、亮度响应、帧边界变化、禁用／图库／X/Z兼容均通过。静音与峰值测试的色块亮度统计由29038升到123319（约4.25倍），峰值120和255夹紧后的整帧一致。

800×600兼容模式3整帧也已通过：1,440,000有效像素，1,276,800个内容区像素与基准一致、163,200个外框覆盖。合计3,897,600像素，其中3,455,872个内容区像素逐位不变。全部HS/VS/DE、帧脉冲、TF地址和帧缓存请求保持一致。

原GUI工程已从综合开始完成HIGH布局布线、码流生成及37输入一致性校验。最终LUT17193/19600、寄存器6399、DSP20/29、9K RAM48/64、32K RAM16/16、PLL2/4；3个内部逻辑时钟和5个CDC数据组0setup/hold错误，最差setup5.330ns／hold0.080ns。外部die时序仍按既有模型与板测范围，不将参考／转发时钟的无端点报告当作外部IO证明。

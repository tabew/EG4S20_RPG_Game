# RPG怪物独立旋转与镜像

本次处理用户截图中的“野兔”等战斗小怪物立绘，只有怪物图层参加变换。血条、文字、地图、篝火及图片播放器保持原来的位置和方向。没有旋转整个HDMI画面，也没有增加篝火菜单。

## 操作

进入RPG并开始战斗，怪物出现后：

| 按键 | 功能 |
|---|---|
| 长按K1约1.2秒 | 循环选择原图旋转角度0°→90°→180°→270°→0° |
| 长按K2约1.2秒 | 左右镜像开／关，镜像应用在所选旋转之后 |
| 短按K1～K4 | 原来的攻击、技能、药水、逃跑，不变 |
| 长按K3 | 全局背景音乐与效果音开／关，不改变怪物方向 |
| 长按K4 | 原来的返回播放器／设置行为，不变 |

长按K1/K2释放不再产生短按，因此不会顺便攻击或消耗技能。变换请求在下一个帧边界统一生效，避免一帧中途改变方向。方向设置会在离开战斗后保留，FPGA复位恢复0°且不镜像。地图、标题、篝火、图库和设置页不接受怪物变换；播放器原长K1 HUD、长K2彩条仍按原逻辑工作。

当前镜像是左右镜像；与180°旋转组合也能得到原图上下翻转的效果。旋转角度是原图的旋转选档，随后才应用显示左右镜像，两项状态可以组合为八种方向。

## 实现与范围

原怪物源图48×48、4bpp、各自16色调色板，3倍显示为144×144，逻辑窗口固定x240..383/y48..191。新逻辑只改变该窗口对应的源ROM取样坐标，没有复制图像或增加SDRAM缓存。原像素和调色板素材文件保持不变。

- 0°取(u,v)，90°、180°、270°按方形图块坐标变换。
- 左右镜像作用在旋转后的显示图块上。
- 窗口外的ROM读取夹到本怪物首字节，避免负坐标导致无效读取。
- 控制器仅在非播放器、非模式锁定、battle场景且mon_on时接收长按事件；待定状态按帧提交。

本轮逐像素验证还暴露并修正原怪物层两个问题：一是额外字节寄存器使半字节选择错拍、valid比字符层多一拍；现统一为三拍。二是调色板在第15项写回前结束，新增同步ROM排空周期后16项都完成。这些修正仅位于怪物层，其他图层流水线不变。

## 已完成的独立检查

- 实际mon.hex/monpal.hex，独立正向旋转／镜像oracle，不复用RTL的逆变换公式作为期望。
- 25只怪物×8变换×3淡入等级，加上X/Z兼容和复位，618种配置；12,814,848个窗口内RGB比较及387,470个窗口外／稳定检查，零错误。
- 高／低半字节各6,407,424次，包含调色板15的3,672次检查；所有ROM地址均在本怪物1152字节区内。
- 原像素错拍可复现666个错误；只恢复旧调色板结束条件则17个实际源像素产生153个错误，新版本全部通过。
- 真实原始按键映射和生产消抖：7次短按、27次长按，12,679个控制状态检查；短战斗键、长按不漏短按、同拍事件和帧边界、旋转四档、镜像两态、非战斗忽略及声音／模式键互不干扰通过。

完整整帧图层隔离验证已通过：两份实际rpg_video和真实ROM，八种变换共2,457,600个有效像素，窗口外2,291,712个RGB565/RGB888像素逐位一致；窗口内4,096个文字像素保持原覆盖优先级，HS/VS/DE/帧脉冲始终一致。该测试使用可控文字背景验证任意其他图层不变，不冒充实际篝火游戏实拍。

已实际从原EG4工程syn_1重新综合，再以HIGH完成phy_1布线和码流生成。37源与冻结快照一致，三个内部逻辑时钟和5个CDC数据组0setup/hold错误；路由LUT15713/19600、reg5822、RAM9k45/64+32k16/16、DSP17/29、PLL2/4，最差setup5.482ns/hold0.104ns。外部器件IO仍按既有模型与实物边界，不将无端点时钟当作独立IO时序证明。

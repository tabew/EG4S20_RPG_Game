# 玩法说明

一块板子、四个按键、一条命。目标是打穿五个区域，每个区域最后有位首领。

---

## 一、开机之后

上电（或下载完成）后直接进标题页：

| 按键 | 作用 |
|---|---|
| **1** | 开始冒险 → 选职业 |
| **2** | 看动态插图（篝火夜景，可按 3 暂停） |

选职业页：

| 按键 | 职业 | 生命 / 魔力 | 攻 / 防 | 特点 |
|---|---|---|---|---|
| **1** | 剑士 | 130 / 40 | 13 / 9 | 皮厚、技能破甲中等，稳 |
| **2** | 法师 | 92 / 90 | 11 / 5 | 血薄蓝多，技能倍率最高 |
| **3** | 游侠 | 106 / 56 | 11 / 7 | 中庸，技能破甲最强 |

## 三、一局是怎么走的

```
标题 → 选职业 → 地图
                  ├─ 1 探索 → 随机遇敌 → 战斗 → 打赢回地图
                  ├─ 2 商店 → 买补给 / 永久强化
                  ├─ 3 休息 → 花 10 金回复
                  └─ 4 打首领（要先在本区讨伐满 4 只小怪）
```

**流程规则：**

1. 每个区域探索时会从本区 **4 种小怪**里随机遇到一只
2. 讨伐数攒到 **4/4**，按 **4** 才能挑战本区首领
3. 打赢首领后，再按 **4** 进入下一区（第 5 区的首领打完就通关）
4. 死了不结束——扣掉**四成金币**，讨伐数清零，半血复活回地图

## 四、战斗怎么算

**普通攻击**：伤害 ≈ (攻击 − 敌人防御/2) × 0.88~1.11
**技能**：先按职业倍率放大攻击、再按职业破甲比例削减敌方防御，同样有 ±12% 浮动

| 职业 | 技能倍率 | 技能只看多少防御 | 耗蓝 |
|---|---|---|---|
| 剑士 | ×1.9 | 30% | 10 |
| 法师 | ×2.1 | 20% | 14 |
| 游侠 | ×1.75 | 50% | 12 |

（普通攻击固定按 50% 计敌方防御，所以只有剑士和法师的技能算"破甲"，游侠的技能只是把攻击放大。）

打高防御的怪（石魔、巨魔、首领）时普通攻击会被削得很惨，**必须用技能**。
游侠在高防敌人面前偏吃力，建议靠等级和护符补攻击。

**升级**：经验满了自动升，生命 +26、魔力 +8、攻击 +4、防御 +2，并且**回满**。

**药水**：按 3 会自动用最高级的那种——大药水(+150) → 药水(+60) → 药草(+30)。

## 五、钱怎么花

| 阶段 | 建议 |
|---|---|
| 前期（第 1~2 区） | 攒钱买**药草**就够了，别急着强化 |
| 中期（第 3 区起） | 优先**力量护符 / 守护护符**（+3 永久，不会丢） |
| 后期 | 大师之证（攻防各 +3）比单买一件划算 |

**休息**（10 金）回 `生命×11/16 + 15`，比买药便宜，**回城前先休息再买药**。

---

## 六、几条实用策略

1. **打小怪别用技能**——攒蓝留给首领。普通攻击能过就别浪费。
2. **血低于一半就用药**，不要赌下一击能打死对面：敌人反击是必中的。
3. **讨伐满 4 只先别急着打首领**，先去商店补满药、把血拉满。
4. **首领战开局先看血条**：首领血条很长，做好打 8~12 回合的准备。
5. **逃跑成功率 10/16**（约六成），血量实在见底时可以赌。
6. 死了只扣四成金币，**不用重开**——复活接着打就行。

## 七、在电脑上玩（没有板子）

```bash
# 改按键脚本，一行一个键（1~4）
sim/iverilog/keys.txt

# 跑：编译 → 仿真 → 出图
sim/iverilog/run.bat
```

每按一次键存一张 `preview/sim/frame_NN.png`，按顺序看就是一局的过程。
**一路写 1** 会自动"探索 → 打 → 回地图 → 再探索"，能一路打到首领。

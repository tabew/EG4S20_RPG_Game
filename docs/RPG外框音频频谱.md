# RPG外框实时音频频谱

用户确认要替换的是战斗画面最外侧的一圈红色边框，不是怪物或玩家的红色生命条。本版仅在RPG战斗场景把外框变成八频带彩色频谱；文字、生命条、怪物区域和内部框保持原样。标题、地图／篝火、商店、结局和图片播放器仍使用原来的画面布局。

## 操作与效果

进入RPG战斗后自动显示，不需要新增按键。上下边框是分组的小频谱柱，左右边框向内跳动，颜色由青蓝向绿、黄及高峰红色变化。没有信号时回落到暗色细边。

- 背景音乐与事件效果音都参加分析，音效发生时会反映到频带高度。
- 长K3声音关闭后输入数字零，频谱逐渐回落；恢复声音后随新样本重新升起。
- 短K1～K4仍是战斗操作；长K1旋转怪物、长K2镜像怪物、长K4返回播放器，功能不变。
- 图库的普通短K3仍暂停／恢复图片，设置短K3仍缩放。原可选音高包络彩条未改，本次新外框使用独立的真实FFT结果。

频谱柱显示的是频带峰值和音量动态，不是固定定时动画。持续单音时对应频带可能稳定，不应期待每帧无规则乱跳。

## 音频分析

分析器直接使用HDMI编码器导出的48kHz取样节拍，采集同一有符号PCM混音；静音门控一致。全部逻辑在像素时钟域，不新增音频跨时钟通道。

256点定点FFT，每256样本分析一次，约187.5次／秒；矩形窗，单频点间隔187.5Hz。八级蝶形每级除2，使用一个共享18×16乘法器和块RAM。正频率分组：bin1、bin2、bin3..4、5..8、9..16、17..32、33..64、65..127，忽略DC与Nyquist。每组取abs(real)+abs(imag)的最大值作幅度近似，然后压缩到0..120，快速上升、每分析块下降2单位。

这是真实离散音频频谱，但属于视觉化，不是精密频响仪：存在矩形窗泄漏、187.5Hz分辨率、定点舍入和幅度近似。原声源有效精度仍是约32kHz更新的8位PSG，经保持采集到48kHz HDMI；不将24位LPCM容器称为24位声源。

## 画面边界

640×480模式仅替换外侧16像素的边框格：x0..15／624..639，或y0..15／464..479。内部x16..623且y16..463逐像素保留。800×600兼容模式按原逻辑坐标对应外侧约20物理像素。生命条与文字位于内容区，不根据“红色像素”粗暴替换。

频带数据与启用状态在垂直消隐按帧快照，避免半帧换高度。最终RGB流水线、HS／VS／DE、帧脉冲和TF读取时序保持原样。

## 验证

- 独立浮点DFT检查99帧、每帧127个正频点，最大实部／虚部误差4.0831个归一化PCM单位。八单音、混合音、递增幅度、正负DC、静音、冲激、噪声、PSG保持采样、连续525／833拍采样和静音回落／恢复均通过。
- 访存优化版与初版逐周期比较2,553,399拍一致；优化版99帧频点及输出记录也逐字相同。
- 已完成生产640×480外框公开RGB验证：17整帧、5,222,400像素，内容区4,630,528次基准比较、417,792次边框oracle比较；生命周期、帧中修改延后生效、静音零值、不同频带、超范围值夹紧、图库禁用、X/Z默认兼容及全部时序一致。
- 实际音乐PCM链路已验证525拍采样，FFT与HDMI收到相同采样；真实长K3静音后纯零块开始精确按2单位回落。整段回落与最终采用版本的短回归结果随发布记录保存。

初版布局因FFT工作RAM被综合成两份分布式存储，M-Slice4951超过4900。等价的单读写地址写法使工作存储推断为块RAM，隔离综合LUT18564→17825、FFT使用3块RAM与1DSP。没有删掉音乐、缩放、缓存或怪物变换来换资源。

最终版已在原EG4工程从syn_1重新综合，并完成HIGH phy_1布线和码流生成。路由后LUT17150/19600、寄存器6388、9K RAM48/64、32K RAM16/16、DSP18/29、PLL2/4；三个内部逻辑时钟及5个CDC数据组0setup/hold错误，最差setup5.482ns／hold0.091ns。37输入与最终快照一致，频谱没有引入新的时钟域。

# 优先测试：即时响应与固定竖线候选

优先SRAM下载本目录eg4s20_response_lines.bit。保持现有分离器、音箱及640×48024位素材不变。请勿先写Flash。

1. 自动播放加载期间短按并松开K3，应保留当前已经显示的画面，不再把后台下一张加载完后显示出来才停。
2. 加载期间短K4应取消未显示后台图并切换模式。首图尚无前帧时仍需完成初次读取。
3. 检查原照片中的四条重复细竖线是否消失/减少/不变。该结果必须实测，本目录不声称竖线已经在板上消除。
4. 当前是标准640×480/60Hz(VIC1)，像素25.2MHz、串行126MHz；SDRAM/SPI仍50MHz/+90°，PLL2/4。默认BARS关闭；长K2可开启，长K1隐藏HUD看原图。
5. 连续滴声是预设48kHz采样的1kHz测试音，长K3静音。上一/下一张仍有约0.92MB文件的读卡耗时，不能把整图读取伪称为瞬间。

完整说明：项目docs/响应与固定竖线-候选版验收.md。

回归包含2,764,800完整帧像素、1～128突发首尾/跨行/银行、独立5.4/9ns模型、CRC后取消、待提交取消/同拍换帧、两种HDMI解码与实际视频第一/最后像素。源和工具证据在本目录JSON/area/timing/SHA文件。
